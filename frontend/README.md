# SupportApp frontend

Frontenddelen för SupportApp 2.0.

## Struktur

- `public/brand/` – statiska varumärkesfiler som appikon/favicon
- `src/assets/logos/` – LM Improve IT- och SupportApp-logotyper
- `src/assets/images/` – övriga bilder och illustrationer
- `src/components/` – återanvändbara UI-komponenter
- `src/layouts/` – sidlayouter och navigation
- `src/pages/` – vyer som Login, Dashboard och Tickets
- `src/services/` – API- och auth-anrop
- `src/styles/` – globala stilar och designtokens
- `src/hooks/` – återanvändbara React-hooks
- `src/types/` – TypeScript-typer
- `src/utils/` – hjälpfunktioner

## Logotyper

Lägg originalfilerna i `src/assets/logos/`. Behåll gärna SVG som SVG. Appikon/favicon och andra filer som ska kunna nås direkt från webbläsaren läggs i `public/brand/`.
